# mgu-zh-tw-repo

iDrive 7 (MGU) 車機 App 的繁體中文（台灣用語）來源倉庫：Drag Timer、Brake Test、Redline、Fault Scanner、Warm-Up、G-Force、M Vitals、Live Data、eDrive、Service、Virtual Dyno。
原作者程式與簡體中文翻譯見 cauliflowermossgrape/idrive7-apps（MIT）；本倉庫只加繁體中文顯示層，詳見 NOTICE.zh-TW.md。

這是給 MGU Store／updater 使用的來源（根目錄 `mgu-repo.json`），由車機端用自己的 SDK 本地建置，倉庫內沒有預編譯 App。
Store 內以「GitHub 來源」加入本倉庫後可看到各 App；請先確認車上相依元件（idrive7-renderd、mgu-inputgate）已由原作者來源安裝。
